# Minecraft Blender Nametag

Dynamic Minecraft-style nametag for Blender.

## Features

- Editable player name
- Automatic background resizing
- Minecraft-style appearance
- Driver-based width adjustment
- Easy to scale and reuse in animations

## How to use

1. Open `Minecraft_Nametag.blend`
2. Select the text object
3. Enter Edit Mode
4. Change the player name
5. The background adjusts automatically

## Blender version

Tested with Blender 4.5.
